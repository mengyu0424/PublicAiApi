## WebService 表格化入参改造

用户需求：调用方式改为「API / WebService」两项；WebService 模式入参从手填 XML 改成 Excel 式表格（点按钮加行，每行填名称/值），方法名与命名空间在表格上方单独输入；不要手填 XML；做好旧数据兼容。

### 实现要点
- `Models.cs`：`ApiItem` 新增 `WsMethod`/`WsNamespace`/`WsParams` + `WsParam` 类；`Validate` 给旧数据补默认值，并从旧手填 XML 请求体 `ParseMethodXml` 解析回填表格。
- `WebService.cs`（`RequestTypes`）：新增 `ModeNames`（API/WebService 两项）、`ModeIndex`/`ModeRequestType`（内部保留 SOAP 1.1/1.2）、`DefaultSoapNamespace`、`BuildMethodXml`（表格→方法 XML，转义值、跳过空名行）、`ParseMethodXml`（旧 XML→表格）。
- `StudioWindow.xaml`：调用方式下拉由代码绑定 `ModeNames`；请求体 Tab 内 `JsonBodyPanel` 与 `WsBodyPanel` 并列切换；表格行用代码动态生成 Grid（列宽常量 42/210/*/54），表头在 XAML。右上角格式化按钮组命名 `BodyFormatActions`，SOAP 模式隐藏。
- `StudioWindow.xaml.cs`：`UpdateCurrent` 在 SOAP 模式把表格拼成 `current.Body`（不再写 requestBody.Content——曾因在 TextBox change block 内重入 `JsonEditor.Content` 的 IsUndoEnabled 抛异常）；发送前显式校验方法名；Action 自动推断基于 `SoapMethodXml()`。
- 测试：`SmokeTests.cs` 加 `WsTable()`（122 项）；`WpfSmokeTests.cs` 重写 `WebServiceUi` + 新增 `SendWsThroughWorkBench`（82 项）。全部通过。
- 示例：`examples/webservice-calculator.json` 改为新表格字段；`webservice-calculator-simple.json` 保留为旧格式兼容演示。README 同步更新。

## 后续简化：Action 全自动 + 方法名取自地址 ?op=

用户反馈「Action 是干什么的？不需要这么复杂，我直接写地址 http://100.2.2.217:8089/HospitalService.asmx?op=GetBoxInfo，GetBoxInfo 就是方法名」。

- `WebService.cs`：新增 `RequestTypes.MethodFromUrl(url)`，从 `?op=XXX` 或 `...asmx/XXX` 取方法名，非法 XML 名称返回空；`VerifyName`/`Unescape` 私有辅助。
- `StudioWindow.xaml`：删除 Action 输入框与「自动」勾选框（原 `SoapOptions` Grid），改为只读提示 `SoapActionHint`（灰色小字，显示自动生成的 Action）。方法名/命名空间 ToolTip 同步更新。
- `StudioWindow.xaml.cs`：删掉 `SoapActionChanged`/`AutoSoapActionChanged`/`updatingSoapAction`；Action 一律自动（`UpdateCurrent` 写入 `InferSoapAction`，`AutoSoapAction=true`）；`AddressChanged` 调 `SyncMethodFromUrl()` —— 地址里的方法名变化时自动填方法名，但用户手改过方法名后不再覆盖（用 `urlMethod` 字段判断是否还在跟随）；切换 WebService 不再塞 `YourMethod` 占位。
- 测试：核心 128 项（新增 `WsAddress()` 6 项）、WPF 83 项，全通过；README 与「已实现」条目同步。
- 注意：命名空间若与服务 WSDL 的 targetNamespace 不一致，Action 与报文都会不对，这时改「命名空间」输入框即可（Action 随之更新）。
